Blocks
● Gold — chain block. Confirmed by consensus.
● Violet — DAG block. Valid, awaiting validation.
Glow brightness = consensus strength.
Larger size = referenced by more blocks.
Faint ring around block = a parent — others build on it.
Connections
Threads link blocks to their parents. Gold thread = chain-to-chain. Blue thread = DAG connection. Each has a unique fixed shape — like a fingerprint.
Pulses ◎
Expanding rings = consensus confidence. Golden = chain. Violet = well-connected DAG. None = uncertain.
Particles & Strands
Floating dots = transaction flow between blocks.
Bottom strands = transactions inside each block. More strands = heavier activity.
Warp Grid
Background lines bend toward consensus — like gravity warping space. Strong agreement reshapes the network's geometry.
Speed
Blocks rise as they age. New blocks race upward. Old chain blocks slow down — settling into consensus history. The chain tip is always advancing.
Thorns
Small spikes radiating from blocks. Parent blocks (referenced by others) grow more thorns. Transaction-heavy blocks also grow additional thorns. A visual sign of influence.
This is a partial view — a sliding window of ~70 blocks from a DAG of millions. A balance between real-time data and cinematic interpretation.
