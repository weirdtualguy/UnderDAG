# UnderDAG
Live Kaspa BlockDAG consensus visualization.

Watch the Kaspa network form consensus in real time — each shape is a real block, each thread a real connection. Gold blocks represent the chain, violet blocks the supporting DAG. Glow intensity reflects validation strength, warp lines bend toward consensus clusters, and transaction strands reveal economic activity.

Features:
• Real-time block streaming from Kaspa API
• Tap any block for full API data (hash, time, transactions, parents, children)
• Consensus gravity — grid lines bend toward trusted regions
• Unique connection fingerprints frozen at block creation
• Transaction fringe shows activity per block
• Cinematic glassmorphism UI with contextual guide

Tech: Vanilla JavaScript, Canvas 2D, Kaspa REST API, GitHub Pages.
